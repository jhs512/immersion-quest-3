## 수업 교육 목표

## 대상과 선수 지식

- 자바 백엔드 과정 초반 학습자. R1~R3에서 값·mut, 조건·반복·함수, 이동·빌림을 Rust로 실행해 봤어요.
- R1의 let mut와 {이름} 출력, R2의 for 반복과 함수 반환을 권장해요.
- R3의 이동(E0382)과 & 빌림을 권장해요. Java의 null이나 예외 지식은 요구하지 않아요.

## 제작 범위

- struct 정의 읽기와 필드 읽기·변경, vec!·{:?}·len()·push, for x in &v, get과 Option, match, Result와 match, parse::<i32>, None·Err를 실제 값과 구분하기를 다뤄요.
- 두 챕터·네 단원·열두 스텝에서 작은 빵집의 상품·가격 목록·주문 수량이라는 같은 상황을 이어 가요.
- 모든 스텝은 준비 코드의 1~2줄을 고쳐 실제 rustc --edition=2024로 컴파일·실행해 판정해요.

## 근거와 확인 한계

- 구조체는 이름 붙은 필드로 관련 값을 묶는다. 필드는 점 표기로 읽고, 필드를 바꾸려면 인스턴스 전체가 mut여야 한다. — Rust 공식 책 5.1절 확인. E0594와 필드 출력은 rustc 1.95.0 --edition=2024로 실측했어요.; 확인 2026-11-02. [원문](https://doc.rust-lang.org/book/ch05-01-defining-structs.html)
- vec!으로 Vec을 만들고 push로 끝에 더한다(mut 필요). 인덱스 읽기는 범위 밖에서 패닉하고 get은 Option을 돌려준다. for x in &v로 빌려 반복한다. — Rust 공식 책 8.1절 확인. E0596·E0382·패닉(index out of bounds)을 rustc 1.95.0으로 실측했어요.; 확인 2026-11-02. [원문](https://doc.rust-lang.org/book/ch08-01-vectors.html)
- Option<T>는 Some(T)와 None으로 값의 있음·없음을 타입으로 나타낸다. — Rust 공식 책 6.1절 확인. Some(1800)·None 출력을 실측했어요.; 확인 2026-11-02. [원문](https://doc.rust-lang.org/book/ch06-01-defining-an-enum.html#the-option-enum-and-its-advantages-over-null-values)
- match는 패턴으로 갈래를 고르고 감싼 값을 이름에 묶는다. 모든 경우를 다뤄야 하며 빠지면 컴파일되지 않는다. — Rust 공식 책 6.2절 확인. None 갈래를 지운 E0004를 실측했어요.; 확인 2026-11-02. [원문](https://doc.rust-lang.org/book/ch06-02-match.html)
- Result<T, E>는 Ok(T)와 Err(E)로 성공과 실패를 나타내고 match로 처리한다. 문자열 parse는 Result를 돌려준다. — Rust 공식 책 9.2절 확인. parse::<i32>의 Ok·Err 갈래 출력을 실측했고 오류 메시지 문구는 쓰지 않아요.; 확인 2026-11-02. [원문](https://doc.rust-lang.org/book/ch09-02-recoverable-errors-with-result.html)

스텝 코드: stp_b778440e-0a3f-40f6-8e78-4b759474a65c
