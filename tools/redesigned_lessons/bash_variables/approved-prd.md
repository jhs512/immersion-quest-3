## 수업 교육 목표

- 현재 셸에 이름=값으로 값을 담고 "$이름"으로 꺼내요.
- 공백이 든 값을 담을 때와 꺼낼 때 따옴표가 하는 일을 구별해요.
- 없는 변수와 지운 변수가 빈 값이 된다는 것을 알고 변수로 파일 명령을 써요.

## 대상과 선수 지식

- Bash 기본 명령(echo, cat, ls, mkdir, 리다이렉션)을 배운 학습자예요.
- echo로 글을 출력하고 > 로 파일에 쓸 수 있어요.
- ls, cat, mkdir를 실행할 수 있어요.
