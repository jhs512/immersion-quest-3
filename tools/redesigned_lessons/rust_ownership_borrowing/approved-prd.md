## 수업 교육 목표

- 복사·이동·clone 뒤 사용할 수 있는 이름을 구분해요.
- 읽기 빌림과 변경 빌림을 목적에 맞게 골라요.

## 대상과 선수 지식

- 자바 백엔드 과정 초반 학습자. R1에서 값·mut를, R2에서 조건·반복·함수를 Rust로 실행해 봤어요.
- R1의 let·let mut·{이름} 출력·비교로 만든 bool을 권장해요.
- R2의 함수 인자와 반환을 권장해요. Java의 참조나 메모리 관리 지식은 요구하지 않아요.

## 제작 범위

- String::from과 push_str, 정수의 Copy, String 이동과 E0382, clone, 함수로 넘기는 이동과 돌려받기, &String 읽기 빌림, 역참조 *, &mut 변경 빌림, 변경 빌림 겹침(E0499)을 다뤄요.
- 두 챕터·네 단원·열 스텝에서 작은 서점의 책 제목과 재고라는 같은 상황을 이어 가요.
- 모든 스텝은 준비 코드의 1~3줄을 고쳐 실제 rustc --edition=2024로 컴파일·실행해 판정해요. 소유권 판정은 컴파일러 진단과 실제 출력으로만 해요.

## 제외 범위

- 명시적 lifetime 표기, 스마트 포인터, 사용자 정의 Drop, raw pointer, unsafe, 동시성은 다루지 않아요.
- 메모리 그림·코드 흐름 보기·이동 뒤 남은 비트 표시는 쓰지 않아요. Rust가 추적형 GC를 쓴다고 설명하지 않아요.
- String::len은 쓰지 않아요. UTF-8 바이트 수와 글자 수를 섞지 않기 위해서예요.
- &str 매개변수로의 일반화, 섀도잉, 슬라이스는 문제로 만들지 않아요. &str을 쓴 다른 정답은 받아들여요.

## 근거와 확인 한계

- String은 힙에 늘릴 수 있는 문자열을 소유한다. 다른 변수에 넣으면 이동해 원래 변수는 무효가 되고, 정수 같은 Copy 타입은 복사된다. clone은 깊은 복사를 만든다. 함수 인자 전달과 반환도 이동이다. — Rust 공식 책 4.1절 확인. 이 수업은 E0382·출력을 rustc 1.95.0 --edition=2024로 실측했고 메모리 배치는 설명하지 않아요.; 확인 2026-11-02. [원문](https://doc.rust-lang.org/book/ch04-01-what-is-ownership.html)
- &로 소유권 없이 참조를 넘긴다. 참조로는 기본적으로 값을 바꿀 수 없고 &mut가 필요하다. 같은 값에 대한 변경 참조는 동시에 하나만 있을 수 있으며, 참조의 범위는 마지막 사용까지다. — Rust 공식 책 4.2절 확인. E0596·E0308·E0499를 rustc 1.95.0으로 실측했어요.; 확인 2026-11-02. [원문](https://doc.rust-lang.org/book/ch04-02-references-and-borrowing.html)
- 역참조 연산자 *는 참조가 가리키는 값을 따라간다. 참조와 정수를 바로 비교하면 타입이 맞지 않는다. — Rust 공식 책 15.2절의 역참조 설명 확인. *stock < 3과 *stock -= 1의 동작, E0308·E0368을 rustc 1.95.0으로 실측했어요.; 확인 2026-11-02. [원문](https://doc.rust-lang.org/book/ch15-02-deref.html)

### 값 전달

교육 목표: 값을 넘긴 뒤 복사와 이동의 결과를 구분해요.

#### 소유한 문자열

교육 목표: String을 만들고 늘려요.

공통 전제: 작은 서점의 책 제목을 String으로 다뤄요. 각 스텝은 준비된 main.rs에서 새로 시작해요.

**title을 String::from으로 만들어 늘리세요**

스텝 코드: stp_03132086-eee4-46c9-8e08-19a6c3bc2d27

교육 목표: String::from으로 늘릴 수 있는 소유 문자열을 만들고 push_str로 끝에 글자를 붙여요.

### 빌려 쓰기

교육 목표: 소유권을 넘기지 않고 함수에 값을 빌려줘요.

#### 읽기 빌림

교육 목표: &로 빌려 읽고 호출 뒤에도 원래 값을 써요.

공통 전제: 읽기만 하는 함수에 제목과 재고를 빌려줘요. 함수를 부른 뒤에도 원래 이름이 필요해요.

**show에 제목을 빌려주세요**

스텝 코드: stp_685ee8ed-ad0b-4b97-90a1-8734e5323b73

교육 목표: 읽기만 하는 함수에는 &String으로 값을 빌려주고, 호출 뒤에도 원래 이름을 써요.

대표 문제. 준비 코드는 show(title: String)에 title을 넘긴 뒤 다시 출력해 E0382로 실패한다. 매개변수를 &String으로 바꾸면 호출이 아직 String을 넘겨 E0308이 난다. 호출을 show(&title)로 고쳐 MQ를 두 번 본다. show(title.clone())도 출력은 같지만 읽기만 하는 함수에 복사본이 필요 없다고 짚는다. 채점은 title을 String::from("Rust")로 바꿔 Rust 두 줄을 요구하고, 호출 뒤 출력 삭제와 상수 출력을 거절한다. 출력만 보는 채점이라 clone 풀이는 막지 못한다. 이 한계를 해설과 PRD에 밝힌다.

***로 참조가 가리키는 재고를 비교하세요**

스텝 코드: stp_c54f7425-60ec-4b0f-bd62-9445c3a0ddc8

교육 목표: &i32로 빌린 정수를 *로 역참조해 비교해요.

is_low(stock: &i32)는 stock < 3을 돌려주려 해 E0308이 난다. 참조와 정수는 바로 비교할 수 없다. *stock < 3으로 고쳐 부족: true를 본다. 채점은 main의 stock을 5·3으로 바꿔 false를 요구해 true를 적은 답을 거절한다. stock < &3처럼 참조끼리 비교한 답도 맞으니 받아들인다.

#### 변경 빌림

교육 목표: &mut의 변경 권한과 겹침 제한을 구분해요.

공통 전제: 빌린 제목과 재고를 바꿔요. 바꾸는 빌림은 한 번에 하나만 살아 있어요.

**&mut로 빌려 원래 제목을 바꾸세요**

스텝 코드: stp_d6874e87-0613-42b9-98df-549bd6600040

교육 목표: 빌린 값을 바꾸려면 매개변수와 호출 모두 &mut로 빌려야 함을 확인해요.

add_edition(title: &String)이 push_str을 불러 E0596이 난다. 매개변수만 &mut String으로 고치면 호출이 &title이라 E0308이 난다. 호출도 &mut title로 고쳐 러스트 입문 2판을 본다. 함수가 빌려서 바꾼 결과가 main의 title에 남는다. 채점은 title을 String::from("MQ")로 바꿔 상수 출력과 복사본을 빌려준 답(&mut title.clone())을 거절한다.

**first를 다 쓴 뒤에 second를 만드세요**

스텝 코드: stp_a08c5e33-f7ec-4aa1-bb44-5d794ddcdc09

교육 목표: 변경 빌림은 동시에 하나만 살아 있을 수 있고, 마지막 사용 뒤에 다음 빌림을 만들 수 있음을 확인해요.

first와 second가 모두 &mut title이고 first를 second 뒤에서 써 E0499가 난다. 두 push_str의 순서만 바꿔도 first를 second 뒤에서 쓰니 여전히 E0499다(시도 후 되돌림). first.push_str 줄을 let second 위로 옮겨 러스트 입문 2판 개정을 본다. 채점은 title을 String::from("MQ")로 바꿔 상수 출력과 first 사용 줄 삭제를 거절한다.

**sell에는 &mut, show에는 &로 빌려주세요**

스텝 코드: stp_9288afaa-d038-40d3-aa6c-cda84996a19d

교육 목표: 바꾸는 함수에는 &mut, 읽는 함수에는 &로 빌려주고 *로 빌린 정수를 바꿔요.

새 개념 없이 7번의 *와 8번의 &mut를 조합한다. sell(stock: &i32)의 stock -= 1이 E0368을 낸다. 매개변수를 &mut i32로 바꿔도 참조 자체에서 빼려 해 E0368이다. 본문을 *stock -= 1로 고치면 호출이 &stock이라 E0308이 난다. 호출을 sell(&mut stock)으로 고쳐 러스트 입문 재고: 2를 본다. show는 읽기만 하므로 &로 둔다. 채점은 stock 10·title MQ로 바꿔 상수 출력과 복사본을 넘긴 답(&mut stock.clone())을 거절한다.
