# 승인 표·CSV 수업의 실행 검증

- 기준 PRD: `approved-prd.json`, 승인 해시 `e9d4c7cf04be934931db872aeddd05a235441cc33d5e2193d6b583842dc56c53`.
- Windows 검증 환경: Python 3.11.15, pandas 1.5.3, NumPy 1.26.4. 실제 시험 커널을 검증했다는 뜻은 아니다.
- 표 생성 틀과 CSV 읽기 틀을 제공한다. 각 문제는 자기 시작 자료와 코드를 갖춘다. 파일 문제에는 `delivery.csv` 하나만 제공한다.
- `head(3)` 문제는 4·7·1행 자료에서 출력한 DataFrame의 값·행·열과 원본 보존을 확인한다. 출력 정렬·공백으로 채점하지 않는다. 검사 프로세스를 조기 종료한 답안은 완료로 인정하지 않는다.
- 나머지는 준비 코드를 실행하고 의미를 고르는 선택 문제다. 실행이나 해설 재생은 성공 판정이 아니다.
- 공개 실행기 검사는 모든 해설 조각을 실제 판다스로 실행한다. 테스트 출력 비교에서 공백 정렬은 무시한다. 학습자 채점 방식과 해설의 사실 확인을 구별한다.
- 형식이 다른 파일이나 학습자 추가 자료까지 지원한다고 주장하지 않는다. 조건 필터·결측·loc는 이 수업 범위가 아니다.
