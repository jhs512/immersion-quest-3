## 수업 교육 목표

- 셸 변수와 환경 변수를 구별하고 export로 자식 프로세스에 값을 넘겨요.
- 자식은 시작할 때 부모의 환경을 복사하고, 자식의 변경은 부모로 돌아오지 않는다는 것을 확인해요.
- export는 지금 셸에만 영향을 주는 설정이며 영구 저장이 아니라는 것을 설명해요.

## 대상과 선수 지식

- 셸 변수를 담고 꺼낼 수 있는 학습자예요.
- 변수 할당과 "$이름" 확장을 할 수 있어요.
- bash 파일.sh로 스크립트를 실행할 수 있어요.

## 제작 범위

- 부모 Bash와 bash로 띄운 자식 Bash 사이의 값 전달만 다뤄요.
- 비밀값 대신 색 이름 같은 공개 값만 써요.

## 제외 범위

- 명령 한 번의 환경 지정과 실행 인자는 다음 수업에서 다뤄요.
- .bashrc·운영체제 환경 설정 파일은 다루지 않아요.

## 근거와 확인 한계

- 실행하는 명령은 내보낸(export) 변수를 환경으로 받아요. 명령 앞의 할당은 그 명령의 환경에만 더해지고 셸에는 남지 않아요. — 공식 매뉴얼 근거, 실제 PTY Bash에서 부모·자식 출력을 비교해 검증해요.; 확인 2026-10-29. [원문](https://www.gnu.org/software/bash/manual/bash.html#Environment)
