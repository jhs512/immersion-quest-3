# 몰입 퀘스트 3 릴리즈

MQ3 전용 소스·릴리즈 저장소는 [jhs512/immersion-quest-3](https://github.com/jhs512/immersion-quest-3)예요. 원본 jhs512/molip-quest와 별개예요. 소스 공개 범위를 확인하기 전이므로 비공개로 시작해요. 공개 코스·수업 저장소는 그대로예요.

main에 푸시하면 Windows x64 실행 파일을 빌드하고 Inno Setup 설치 프로그램을 만들어요. 설치와 제거가 성공하고 설치 파일 검사까지 통과해야 릴리즈를 게시해요. 새 푸시는 이전 실행을 취소해요. 빌드 작업은 읽기 권한만 갖고, 릴리즈 작업만 콘텐츠 쓰기 권한을 받아요.

릴리즈 태그는 v<앱 버전>-build.<워크플로 실행 번호>예요. 설치 프로그램과 SHA256SUMS를 먼저 초안에 올린 뒤 완성된 릴리즈로 전환해요. [다운로드](https://github.com/jhs512/immersion-quest-3/releases/latest)와 앱 업데이트 모두 이 저장소만 사용해요.

비공개 저장소의 릴리즈는 초대된 계정만 받을 수 있어요. 앱은 학습에 사용하는 gh 로그인으로 업데이트 정보와 설치 파일을 가져와요. 일반 사용자에게 공개 배포하려면 저장소 공개 범위 또는 별도의 공개 배포 저장소를 결정해야 해요. 토큰을 앱이나 워크플로 파일에 넣지 않아요.

설치 이름은 ‘몰입 퀘스트 3’, 경로는 %LOCALAPPDATA%\\Programs\\MolipQuest3예요. 원본 앱과 설치 식별자가 달라요. 자동 업데이트는 이 MQ3 설치를 덮어써요. 기존 로컬 학습 데이터 위치는 변경하지 않아요.

현재 자동 배포 대상은 Windows x64뿐이에요. macOS와 Android 패키징 파일은 원본 자료로 남겨 두지만, MQ3의 로그인·학습 기능을 해당 기기에서 검증하기 전에는 자동 릴리즈에 포함하지 않아요. Windows 코드 서명 인증서는 설정하지 않았어요.

개인 설정, .scratch, 로컬 문서, 빌드 출력, 가상 환경, 의존성 설치 폴더, 서명 키, 강사 전용 정답·암호화 자료는 소스에 올리지 않아요. 로컬의 강사 자료는 그대로 보존하며, 깨끗한 CI 빌드는 그 자료 없이 컴파일돼요. 일반 코스·공개 문제의 풀이와 해설은 유지해요.
