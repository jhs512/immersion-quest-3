# 프로그래머스 실습 화면 관찰

2026-10-02 실제 브라우저에서 자바 입문 수업의 변수 실습을 풀었다.
빈칸에 `int number = 3;`을 입력하고 실행 및 제출 버튼을 눌렀다.
채점 결과는 정답, 정확성 100.0, 합계 100.0 / 100.0이었다.

## 확인한 학습 동선

- 기본 코드는 읽기 전용이고 작성할 부분만 코드 안의 입력칸으로 제시한다.
- 코드 실행과 제출 후 채점을 분리한다.
- 결과 영역은 테스트별 통과 여부, 실행 시간과 메모리, 총점을 표시한다.
- 정답 안내 모달에 다음 강의 보기 버튼을 제공한다. 이 버튼으로 상수 설명에 이동했다.
- 상단 목록 버튼은 현재 페이지 위에 목차 모달을 띄운다.
- 목차에는 파트별 완료 수, 강의별 완료 여부, 현재 진행 중 표시가 함께 있다.
- 목록을 닫고 상단 다음 강의를 눌러 상수 실습으로 이동했다.

## 몰입 퀘스트에 반영할 후보

완료 안내에서 다음 단원으로 이어지는 버튼, 상단 이전/목록/다음 이동,
목차의 현재 단원 표시, 원시 JSON 대신 읽기 쉬운 테스트 결과를 우선한다.
이 문서는 관찰 기록이며 위 후보가 모두 구현됐다는 의미는 아니다.
