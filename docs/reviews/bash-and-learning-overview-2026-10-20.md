# Bash 수업과 학습 정보 해설

사용자의 2026-10-20 추가 지시로 30단계 Bash 수업을 자바 백엔드 과정의 Git 앞에 등록한다. 파일 탐색·생성·출력·쓰기·복사·폴더 복사·이동·삭제와 Vim 편집을 다룬다. 기존 문제 ID·진도는 유지한다.

실습은 파일이 없는 폴더에서 시작하며 다음 단계가 파일·폴더·작업 위치를 이어받는다. 별도 Git 저장소를 만들지 않는다. 실제 Bash 프롬프트로 복귀할 때 명령·종료 코드·위치를 기록하며, 파일 상태만 미리 준비해 놓아서는 통과하지 않는다. 해설 시작 상태는 별도 폴더에 준비한다.

Vim은 실제 PTY에서 실행해 입력 모드·일반 모드·저장·취소·종료를 시연하고 편집 결과를 검사한다. 실행 전 설치 여부를 확인한다. Windows Git Bash의 대화형 Vim·IME 검증은 별도이며 macOS 검증으로 대신하지 않는다.

빈 ls 결과의 의미는 Bash 첫 등장에만 설명한다. 모든 단계에 할 일 번호 목록과 제출 행동을 표시한다.

자바 테스트 첫 문제의 모호한 비교 질문을 구체적인 배송비 기대값·실제값 검사 질문으로 고쳤다. 예측 후 선택하는 문제의 정체성과 판정은 유지한다.

학습 정보 창에는 학습 방법과 목표·방법 해설 버튼을 추가한다. 해설은 목표 항목과 학습 방법 문장을 차례로 강조한다. 문제 실행·답안·파일을 바꾸지 않으며 닫기·Escape·멈춤으로 종료한다. 음성은 공용 발음·온라인/기기 음성 경로를 사용한다.

## 검증 결과

macOS 실제 PTY에서 30단계의 명령·파일 상태·폴더 이동·Vim 편집을 이어서 검증했다. 원래 파일과 위치가 유지되는 재실행도 통과했다. 독립된 네이티브 WebView에서 ls 해설, Vim 한글 편집·저장·종료, 학습자 파일·터미널 보존, 학습 정보 음성·강조·닫기 정지를 검증했다. Chromium과 WebKit의 음성 강조·취소 검증도 통과했다. 설치한 앱에서 과정 첫 수업, 목표 해설의 실제 음성 재생·강조 화면을 확인했다.
