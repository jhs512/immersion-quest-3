# 자바 백엔드 공통 학습 안내 적용

## 요청과 범위

2026-10-20 사용자가 Git 수업에서 합의한 원칙 중 공통 사항을 나머지 자바 백엔드 수업에 적용하도록 요청했다. 이어 앱 표시 이름을 MQ으로 지정했다. 기존 승인된 학습 목표·정답·채점 방식은 유지하는 편집 개정이다.

적용: 값과 식, 조건, 배열, 메서드, 참조, static, 역할·인터페이스, 컬렉션, 스트림, 파일·예외, CRUD, 테스트, 파서, React, Tailwind — 15수업 127스텝.

## 인접 레이어 검토

- 교육 목표·문제 본질: 변경 없음. 식별자, 정답, 실행 코드, 검사, 입력 자료, 선택지 식별자와 정답 키가 그대로임을 비교했다. 기존 완료 기록을 다른 문제로 옮기지 않는다.
- 학습 콘텐츠: 모든 스텝에 시작 상태와 번호 있는 할 일을 표시한다. 각 문제의 관찰 대상을 구체화했다. 예측 문제는 답 선택 뒤 실행·비교, 코드 수정 문제는 수정 전 확인 → 한 곳 수정 → 재실행·비교 → 제출이다.
- 핵심 용어: 변수·메서드·객체 참조·static·CRUD 및 람다·스트림·filter·map·최종 연산은 해당 첫 사용 스텝에서 짧게 안내한다.
- 해설: 기존 실행·코드 강조·결과 설명을 보존하고 제공된 예제로 시연한다는 안내를 앞에 둔다. 문장 공백과 일반 문장 속 가격 표기를 정리했다. 변경한 해설 캐시와 수업·코스 해시를 다시 생성했다.
- 공통 정책: `docs/content-rules.md`에 공통 적용 기준을 기록했다. Git 초기화나 준비 영역 같은 전용 절차는 자바에 적용하지 않는다. 발음은 기존 공용 모듈을 사용한다.
- 빌드: 자바 15수업에도 할 일 번호 순서·단일 영역·마지막 제출 검사를 강제한다.

## 스트림 등록

이미 존재하는 java-streams-1의 10스텝을 유지한다. 제목은 「자바 스트림 · 가격을 고르고 바꾸고 합산해요」다. 람다, filter, map, 지연 실행, 재사용 금지, 합산·빈 결과, Optional, 중복 제거·정렬, 중복 키 병합, 경계값 수정을 다룬다. 과정의 컬렉션 뒤·파일 수업 앞에 등록되어 있다.

## 앱 이름과 호환성

창 제목·첫 화면·사이드바·macOS 앱 이름·설치 안내·Windows 설치 표시·릴리스 표시를 MQ으로 변경했다. 실행 파일명, 번들 식별자, 데이터 폴더, 저장소·진도 식별자는 유지한다. 새 업데이트 코드는 예전 이름의 DMG도 읽을 수 있다. 로컬 설치본은 `/Applications/MQ.app`이며 서명 검증을 통과했다. 원격 게시·릴리스·커밋·푸시는 하지 않았다.

## 로컬 반영과 확인

전체 과정 스냅샷을 검증한 뒤 설치했다. 이전 작업의 Bash/Vim 분리도 함께 포함되어 과정은 20수업 187스텝이다. 최초 설치 비교는 Vim 14문제 추가, 기존 Bash 속 Vim 7문제 제외, 자바 설명 127문제 수정이었다. 이전 스냅샷은 `target/before-java-clarity-snapshots`에 백업했다. 진도 저장소는 변경하지 않았다.

실제 앱에서 MQ 이름, 스트림 14번째 수업·10스텝, 람다 설명, 번호 목록, 1,000·2,000 표기, 기존 Git 5/6 진도를 확인했다.

검증 결과와 상세 로그는 `target/mq-common-content-check.log`, `target/mq-common-tests.log`, `target/mq-brand-update-tests.log`, `target/mq-streams-native.log`에 기록한다. 최초 업데이트 테스트는 이름 변경 때문에 예전 이미지 파일을 찾지 못했다. 구 이름 호환 경로를 추가한 뒤 8개 업데이트 테스트가 모두 통과했다.

추가 검증: 최종 자바 값 수업의 실제 JDK 실행, 전체 74수업 로딩, 실제 Vim 14스텝·재개·무조작 실패 검사, Bash 네이티브 해설·목표 음성 하이라이트 검사를 통과했다. 실행 가능한 순서 조각까지 원문 보존을 별도 비교했다.

스트림 실행 검증: `validate_redesigned_lesson`으로 10스텝의 실제 JDK 출력·정답·오답을 모두 통과했다(7.22초). 네이티브 전체 재생은 다른 창에 가려진 WebView의 화면 갱신 대기로 최초 480초 제한에 도달했다. 추가 재생 검사는 사용자의 현재 앱 작업을 방해하지 않도록 중단했으며 전체 네이티브 통과로 보고하지 않는다. 임시 검사 코드 변경은 되돌렸다. 실제 설치 앱의 스트림 첫 화면과 최종 콘텐츠 표시는 직접 확인했다.

최종 이름은 사용자의 정정에 따라 **MQ**다. `/Applications/MQ.app`에 새 실행 파일을 원자적으로 교체하고 서명 검증했다. 실행 중인 창과 사용자의 편집은 유지했다. 기존 창의 제목은 다음 실행부터 새 이름을 표시한다.
