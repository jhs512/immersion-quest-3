## 검증

- 실제 Windows 앱의 라이트 선택 전후, 다크 선택, 선택 이동·제출 뒤 상태와 로그아웃 확인·성공·실패 화면을 확인했다. 로그아웃은 가짜 계정·임시 프로필·가짜 gh만 사용했다. 실제 사용자 토큰을 지우거나 폐기하지 않았다.
- 로그아웃 7개 검사를 통합 코드에서 Codex가 다시 실행해 통과했다. Claude는 release 모드에서도 7개를 통과시켰다. PR 실습의 인증 호출과 git 자격 증명 경로도 로그아웃을 확인한다. 이 차단을 제거하면 검사가 실패하는 것을 확인했다.
- 로그아웃 취소, 데이터 파일 보존, 재시작, 재연결, 실패 결과 유지, 환경변수 경고, 계정 전환은 native pilot 검사로 확인했다. Mac 실제 로그아웃은 시험하지 않았다. Windows/Mac 배포 과정에 가짜 gh 검사 단계를 추가했다.
- 발음 모듈의 대상 검사 25개와 게시 도구 검사 7개를 Codex가 별도로 통과시켰다. 수업 문장 전체에서 지표 R2와 번호 R2를 구분하는 검사도 수행했다.
- 변경 수업 17개는 실제 채점 검사를 통과했다. 콘텐츠·번들·해설 검사를 통과했으며 바뀐 원문에 대해 해설 도구도 실행했다. 실제 선택형·빈칸형 화면에서 중복 목록이 없고 해설 강조가 유효함을 확인했다.
- 전체 lib 검사의 두 실패는 별도 기준 버전 215b109c에서도 재현됐다. Java 수업 수 기대값 44 대 실제 48, java-trace 원본 해시의 오래된 기대값이다. 이번 변경의 성공 검사로 세지 않았고 이 범위에서 고치지 않았다. 일부 JS 화면 검사에도 기준 버전의 누락 fixture 문제가 있다.

## 공개 수업

새 불변 버전으로 17개를 게시했다. [정처기 0ff2f0c8](https://github.com/jhs512/mq3-course-redesigned-engineer-practical/commit/0ff2f0c8)은 62개 중 14개, [AICE fe287f63](https://github.com/jhs512/mq3-course-redesigned-aice-associate/commit/fe287f63)은 24개 중 3개만 갱신했다. Java 50개는 그대로다.

원격 수업의 변경은 검토한 198개 필드(목표 183·해설 목록 15)와 revision뿐이다. 문제 ID·정답·채점·코드는 그대로다. 기존 태그 17개의 원문도 보존했다. 과정의 다른 수업, 정처기 11개 분류·순서·선수 관계와 이전 띄어쓰기 개선을 보존했다. Codex도 최신 공개 정처기의 62개·11분류·14개 참조 변경·기타 메타데이터 보존을 별도 확인했다.

실제 앱의 Github.prepare_course가 임시 프로필에서 Java 50·정처기 62·AICE 24개를 받아 검증했다. 설치된 사용자의 앱이 갱신을 마쳤다는 뜻은 아니다. 자세한 게시 근거는 [수업 변경 기록](answer-only-todo-2026-11-03.md)에 있다.

## 앱 배포와 검증 한계

수업 문구는 공개 반영됐다. 발음·테마·로그아웃은 앱에 포함되는 코드이므로 새 설치 파일이 필요하다. 통합 소스를 main에 게시해 자동 배포 검사를 시작한다. 빌드 완료와 공개 설치 파일은 GitHub Actions와 Releases의 실제 상태로 확인해야 한다.

문구 검사 앱을 처음 실행할 때 임시 프로필 설정이 빠져 실제 프로필의 환경 준비 화면이 열렸던 실수가 있었다. 해당 작업 프로세스를 중단했고, 이후 화면 검사는 임시 프로필로만 수행했다. 이 사실은 사용자에게 알렸다. 미완료된 전체 native 문제 실행을 성공으로 주장하지 않는다.
