# SQL 스텝의 할 일

스크린샷의 두 열 조회 문제에서는 실행·오류 읽기·실행·제출 안내가 핵심 요구보다 길었다. 오류가 없는 조회에도 오류 문장을 찾으라는 지시가 붙었다.

- SQL 기초 18스텝의 할 일을 설명보다 먼저 보여 준다.
- 첫 항목은 수정할 파일과 해당 스텝의 실제 요구다.
- 두 번째 항목은 열·행·정렬·변경 범위 등 그 문제에서 확인할 결과다.
- 마지막 항목은 SQL 제출이다. 실행 버튼 사용법을 매번 다섯 항목으로 반복하지 않는다.
- 준비 상태, 개념 설명, 정답과 채점 조건, 해설 실행 순서는 유지한다.

예: **이름과 가격 두 열만 조회하세요** (`lesson.sql`). 실행해서 결과의 열이 name, price 두 개뿐인지 확인하세요.

적용 범위는 SQL 기초 18스텝이다. 다른 수업의 전체 문구 검토가 완료됐다는 뜻은 아니다.
