# 코스·수업 변경 이력 형식

`course.json`과 `lesson.json`의 선택 필드 `change_history`는 제작자가 남긴 변경만 담는다. 학생의 업데이트 클릭이나 학습 이벤트로 자동 생성하지 않는다. 오탈자 수정도 기록한다. 기존 파일에 이 필드가 없으면 빈 이력으로 읽는다.

각 항목은 다음 필드를 갖는다.

- `at`: 변경 시각. UTC의 `YYYY-MM-DDTHH:MM:SSZ` 형식이다.
- `summary`: 짧은 한 줄 요약이다(UTF-8 240바이트 이하).
- `reason`: 변경 이유 한 줄이다(UTF-8 400바이트 이하).
- `details`: 펼쳐서 볼 세부 내용의 문자열 배열이다. 생략하거나 빈 배열로 둘 수 있다. 최대50개, 항목당8000바이트 이하로 둔다.

이력은 파일당1000개까지 읽는다. 잘못된 날짜나 빈 요약·이유는 후보 검증에서 거절한다. 코스와 설치된 수업의 이력을 모아 시각이 최신인 순으로 보여 준다. 화면에서는 수업 설정의 '변경 이력'을 눌러 열고, 필요할 때 세부 내용을 펼친다. 긴 목록은50개씩 더 볼 수 있다. 외부 프로그램이나 고정 이유 태그를 요구하지 않는다.

학습 정책과 말투는 `content-rules.md`, `voice.md`를 따른다. 이력 필드의 추가가 문제의 고유 코드나 기존 성공을 바꾸지 않는다.
