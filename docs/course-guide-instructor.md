# 수업 안내 사이트의 강사용 실습 자료

첫날 오전 실습은 `site/practice.html`에서 제공한다. 학생에게는 문제, 준비 코드, Excel 자료, 예상 출력이 공개된다. 각 문제의 「정답 보기」「해설 보기」는 강사 비밀번호로 연다.

정답과 해설은 `site/data/instructor.json`에 PBKDF2-SHA-256(310,000회), AES-256-GCM으로 암호화해서 저장한다. 비밀번호와 평문은 사이트나 Git에 포함하지 않는다. 비밀번호는 이 작업 컴퓨터의 Git에서 제외된 `target/course-guide-authoring/password.txt`에 있다. 제작 파일과 평문도 같은 제외 폴더에 보관된다.

한 번 열면 현재 페이지의 메모리에서만 자료를 유지한다. 새로고침하면 다시 비밀번호를 입력해야 한다. 「강사용 자료 잠그기」로 열린 자료를 지우고 다시 잠글 수 있다. 강의 화면을 학생에게 공유할 때는 열린 정답이 함께 보일 수 있으므로 주의한다.

이 방식은 정답의 일반적인 열람과 소스 검색을 막기 위한 정적 사이트 보호다. 서버에서 강사 신원을 인증하거나 열람을 기록하는 권한 시스템은 아니다. 비밀번호를 아는 사람은 누구나 복호화할 수 있고, 열린 자료는 복사·저장할 수 있다. 비밀번호 변경 시 새 비밀번호와 새 salt/IV로 자료를 다시 암호화하고 배포해야 한다. 이전 배포의 암호화 파일과 그 당시 비밀번호로 얻은 자료를 회수할 수는 없다.

학생 Excel은 가상 카페 매출 5행이다. 각 문제는 파일을 새로 읽으며, 앞 문제의 변수나 결과에 의존하지 않는다. 참조 답안은 Python 환경에서 각각 실행해 예상 출력과 비교한다.
