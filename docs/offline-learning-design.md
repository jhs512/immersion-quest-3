# 학생용 오프라인 학습 설계

설계 인터뷰 진행 중. 아래는 사용자가 확정한 결정이며 구현 완료를 뜻하지 않습니다.

- 학생은 가입·로그인 없이 미리 제공된 클래스룸을 열어 학습합니다.
- 클래스룸 → 수업 → 챕터 → 단원 순서이며 단원에는 개념과 문제가 있습니다. 작성자가 배치 순서를 정합니다.
- 기본 프로그램 설치하기 메뉴에서 uv로 앱 전용 Python과 패키지를 준비합니다. 설치가 실패하면 설치된 Claude 또는 Codex CLI를 통해 복구합니다. 다운로드와 온라인 AI 호출은 인터넷이 필요합니다.
- 개념은 읽었어요 표시, 문제는 채점 통과로 완료됩니다. 단원 안의 모든 항목을 완료하면 단원이 완료됩니다.
- 모든 챕터와 단원에 자유롭게 이동하며 이어하기로 마지막 학습 위치를 엽니다.
- 수업 구조 JSON, 설명 Markdown, 실습 Python 및 데이터 파일을 ZIP으로 묶어 공개 GitHub 릴리즈에 배포합니다. 내려받은 수업은 오프라인에서도 사용할 수 있습니다.
- 개념과 문제마다 고정된 고유 코드와 수정 버전을 둡니다. 제목이나 위치가 바뀌어도 학습 기록은 유지합니다.
- 수업이 수정되어도 완료 기록을 유지하고 변경된 항목에 업데이트됨을 표시합니다.
- 삭제된 항목의 학습 기록은 보관하되 화면과 현재 콘텐츠 진도 집계에서는 제외합니다.
- 학생에게 불필요한 확인 질문을 최소화하고 Windows의 일반적인 보안·설치 관례를 따릅니다.
- 설치 실패 시 AI 자동 복구는 한 번의 실행에서 최대 10회 시도합니다. 실패하면 설치 실패와 원인을 표시하고 다시 시도 버튼을 제공합니다. 다시 시도는 새로운 최대 10회 실행을 시작합니다.
- AI 제공자는 학생이 선택할 수 있으며 기본값은 Claude입니다. Codex도 선택지로 제공합니다.
- OmniRoute 연결이 설정된 경우 우선 사용합니다. 설치 닥터에 OmniRoute 설치·연결 안내를 포함하고 Claude, OpenAI/Codex, Google Gemini 등 대표 서비스의 가입·로그인 또는 API 키 준비 방법을 안내합니다. 모든 서비스 가입을 필수로 요구하지 않고 선택한 연결에 필요한 절차만 보여줍니다.

## 아직 결정할 내용

- AI 복구의 구체적인 작업 범위와 설치 로그 처리.
- 수업 업데이트를 적용하는 시점과 실패 시 처리.
- 개념 콘텐츠의 지원 형식과 문제의 채점 유형.
- 수업 작성 및 배포 작업 흐름, 초기 클래스룸과 수업 구성.
- 진도와 풀이의 백업·이동 범위.

전체 결정의 공동 확인 후 구현합니다.
