# 정보처리기사 첫 C 코드 읽기 수업: 언어 근거

확인일: 2026-10-19 (한국 시간). WG14의 공개 **N1570 위원회 초안(2011-04-12)**을 직접 열어 아래 절을 확인했다. C11 계열의 공개 언어 참조이며 현행 최종 ISO 표준 전체나 Q-net 채점 환경을 확인했다는 뜻은 아니다. 수업 PRD·본문·문제·정답·실행기를 제작하지 않았다.

## 직접 확인한 규칙

각 링크의 `page`는 PDF 뷰어의 1부터 시작하는 물리 쪽수다. 문서에 인쇄된 쪽수와 다르다.

| 대상 | 확인한 사실 | 1차 근거 |
| --- | --- | --- |
| 초기화한 정수 지역 변수 | 스칼라 초기값은 초기식의 값이 변환된 결과다. 자동 저장 기간의 초기식은 선언에 도달했을 때 평가되어 저장된다. | [N1570 6.7.9 ¶11, 6.8 ¶3](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=158) |
| 대입 | 단순 대입은 오른쪽의 현재 값을 변환하여 왼쪽 객체의 저장값을 바꾼다. 초기화·대입은 살아 있는 수식 관계를 등록하는 동작이 아니다. | [N1570 6.5.16.1 ¶2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=120) |
| 순차 실행 | 별도 제어 흐름이 없으면 문장들은 순서대로 실행된다. 한 완전식과 다음 완전식 사이에는 순서점이 있다. 이를 모든 표현식 내부의 왼쪽부터 평가 규칙으로 확대하지 않는다. | [N1570 6.8 ¶2–4](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=164) |
| 정수 나눗셈 | 정수 `/`는 몫의 소수 부분을 버린다. 양수 7과 2의 나눗셈 결과는 3이다. | [N1570 6.5.5 ¶6](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=110) |
| 단순 if | 조건식이 0과 다르면 첫 문장을 실행한다. `else`가 있으면 조건이 0일 때 두 번째 문장을 실행한다. | [N1570 6.8.4.1 ¶1–2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=166) |
| 정수 출력 | `printf`는 표준 출력으로 쓰며 `%d`는 `int` 인자를 부호 있는 십진수로 변환한다. 출력값과 변수의 저장값을 구분한다. | [N1570 7.21.6.1 ¶8](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=330), [7.21.6.3 ¶1–2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=342) |

## 시험 근거와 실행 근거의 경계

이전 [2026-10-18 시험 조사](engineer-practical-exam-2026-10-18.md)는 Q-net 공식 범위를 프로그래밍 언어 활용 등을 포함한 필답형 시험으로 확인했다. 공식 기준의 C 표준·특정 컴파일러·컴파일 옵션·정수 크기는 미확정이라고 기록했다. 이번 작업은 그 시험 조사를 다시 검증한 것이 아니라 언어 의미만 보강했다. N1570을 참조했다는 사실로 시험이 C11을 채택한다고 주장하면 안 된다.

이번에는 컴파일러를 실행하지 않았다. 실제 플레이어의 C 실행 환경과 시험 출제자의 환경도 확인하지 않았다. 표의 나눗셈 결과는 명세에서 도출한 언어 사실이며 시험 문제나 실행 로그가 아니다.

## 첫 수업 검토 범위와 미확정 사항

이번 확인 범위는 초기화한 `int`, 현재 값의 대입, 순차 실행, 작은 양수의 나눗셈, 단순 조건 분기, 정수 출력이다. 이 범위 안의 자체 예시를 검토할 근거로만 사용한다. 포인터, 미초기화 값 읽기, 범위를 벗어난 계산, 여러 부수효과를 섞은 표현식 등은 범위에 추가하지 않았다.

독립 문제의 초기 상태·정답 판정·출력 공백 규칙·실행 환경 표기·문제 수·교육 순서는 미확정이다. 기초 코드 읽기 수업을 정보처리기사 실기 전체 대비나 공식 기출 재현으로 표시하지 않는다.
