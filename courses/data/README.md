# KPC 수업 자료

C:/works/kpc-lec에 있던 강의 제공 자료를 읽어 앱의 고정된 오프라인 실습 자료로 구성했습니다. 원본 프로젝트는 수정하지 않았습니다. 수강생 명단은 사용하지 않습니다.

- titanic.csv: 기존강사 수업자료/titanic.xlsx를 CSV로 변환. 1309행·14열이며 결측은 유지하고, 열 이름은 한글(객실등급·생존·이름·성별·나이·형제배우자·부모자녀·티켓·요금·선실·탑승항구·구명보트·시신번호·출신목적지)로, 성별 값은 여성·남성으로 바꿨습니다.
- credit.csv: 기존강사 수업자료/default of credit card clients.xlsx의 두 번째 행을 헤더로 읽어 CSV로 변환. 30000행·25열. 열 이름은 한글(고객번호·신용한도·성별·학력·결혼·나이, 상환_9월~상환_4월, 청구_9월~청구_4월, 납부_9월~납부_4월, 다음달 부도)입니다. 교재가 연결한 원자료는 UCI Default of Credit Card Clients입니다.
- stock.csv: 기존강사 수업자료/_ko_stock/stock_data/005930.csv를 그대로 복사. 401행이며 날짜 포함 7열(날짜·시가·고가·저가·종가·거래량·변화율)입니다. 이 고정 파일로만 학습하며 실시간 가격과 섞지 않습니다.
- prices.html: practice/prices.html의 가상 가격 문서. 라이브 사이트 접근 대신 선택자와 문자열 변환 원리를 연습합니다.

실행기는 매번 새 작업 폴더의 data/에 원본 자료를 준비합니다. 학생 코드가 변경한 파일과 이전 실행의 임시 파일은 다음 실행으로 이어지지 않습니다. 학생은 main.py 하나만 편집하며 데이터 파일을 직접 준비하지 않습니다.
- croissant.csv: 수업용으로 만든 가상 자료. 파리바게뜨 공장의 8주(2026-08-03~09-27) 일별 크루아상 판매 기록 56행, 열은 날짜·요일·날씨·기온·판매량이며 판매량 2칸이 비어 있습니다. 요일과 비 오는 날의 효과를 넣어 생성했습니다.
