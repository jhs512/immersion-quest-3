MQ · macOS 설치 안내

Apple Silicon(M1 이후)용 arm64 설치 파일을 받아요.
DMG를 열고 「MQ.app」을 Applications로 옮겨요.

Apple 공증은 아직 설정하지 않았어요.
처음 실행할 때 차단되면 시스템 설정 → 개인정보 보호 및 보안에서
이 앱의 「그래도 열기」를 선택해요.

앱 안의 터미널에서 기존 gh 로그인을 사용할 수 있어요.
필요하면 brew install gh 다음 gh auth login을 실행해요.
Java 수업에는 JDK 25, C 수업에는 Xcode 명령행 도구가 필요해요.
C 도구는 터미널에서 xcode-select --install로 설치해요.

설치와 Python 환경 준비를 함께 하려면 다음 명령을 사용해요.
curl -fsSL https://raw.githubusercontent.com/jhs512/immersion-quest-3/main/packaging/macos/install.sh | bash
