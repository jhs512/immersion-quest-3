MQ · macOS 설치 안내

Mac은 터미널 명령으로 설치하세요.
브라우저에서 DMG를 직접 받아 앱을 옮기지 마세요.

1. Spotlight(⌘ + Space)에서 「터미널」을 여세요.
2. 아래 한 줄을 붙여 넣고 Enter를 누르세요.

curl -fsSL https://raw.githubusercontent.com/jhs512/immersion-quest-3/main/packaging/macos/install.sh | bash

앱과 Java·C·Python 환경을 준비한 뒤 MQ를 열어요.
Apple Silicon Mac(macOS 12 이상)에서 사용하세요.
앱에서 「gh 설치 → GitHub 로그인 → 준비 완료 · 연결 확인」을 누르세요.
C 도구 설치 창이 나오면 설치와 약관 확인을 완료하세요.
설치 결과는 앱의 「환경 진단」에서 확인하세요.
