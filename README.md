# MQ

## Windows · x64

1. [Windows 설치 파일](https://github.com/jhs512/immersion-quest-3/releases/latest/download/molip-quest-3-windows-x64-setup.exe)을 받으세요.
2. 다운로드한 파일을 실행해 설치하세요.
3. 시작 메뉴에서 **MQ**를 여세요. 이전 앱이 실행 중이면 종료한 뒤 다시 여세요.
4. 앱의 **gh 설치 → GitHub 로그인 → 준비 완료 · 연결 확인**을 순서대로 누르세요. 이미 로그인했다면 연결 확인만 누르면 돼요.

첫 실행 시 앱이 Java·C·Python을 진단하고 필요한 도구를 자동으로 준비해요. 정상인 기존 환경은 유지해요. 설치 결과는 **앱 설정 → 환경 진단**에서 확인하고, 실패한 경우 **환경 설치**로 다시 시도하세요.

## macOS · Apple Silicon · 12 이상

### 터미널로 설치

터미널에서 아래 명령을 실행하면 Apple Silicon용 앱을 설치하고 Java·C·Python 환경을 준비한 뒤 **MQ**를 열어요.

```bash
curl -fsSL https://raw.githubusercontent.com/jhs512/immersion-quest-3/main/packaging/macos/install.sh | bash
```

앱에서 **gh 설치 → GitHub 로그인 → 준비 완료 · 연결 확인**을 누르세요.

Java는 CPU를 자동으로 구분해 앱 전용 JDK 25를 준비해요. macOS의 C 도구 설치 창이 나오면 **설치**와 **약관 확인**을 완료하세요. 앱에서 **환경 진단**으로 완료 여부를 확인할 수 있어요.

## 수업 콘텐츠 업데이트

선택한 코스는 열 때와 실행 중 5분마다 GitHub의 새 콘텐츠를 확인해요. 검증을 마친 내용은 수업 목록에서 자동으로 적용해요. 문제를 푸는 중에는 현재 문제와 답안을 유지하고, 목록으로 돌아왔을 때 적용해요. 바로 적용하려면 **수업 설정 → 수업 업데이트**를 누르세요. 업데이트 전 답안도 같은 설정에서 확인할 수 있어요.

게시할 때는 코스 저장소의 `main/course.json`에 수업의 새 `revision`과 `sha256`을 반영해야 해요. 수업 저장소에 커밋만 올리면 기존에 고정한 수업은 바뀌지 않아요. 앱은 수업 전체의 형식과 해시를 확인하고 한 번에 교체해요. 실패하면 기존 콘텐츠와 학습 기록을 유지해요.

기본 세 코스도 같은 갱신 경로를 사용해요. 앱에 포함된 콘텐츠는 첫 설치와 오프라인 시작에 사용해요. 동기화 도입 전에 게시된 구형 코스 세 개는 정확한 내용 해시로 식별해 자동 되돌림을 막아요. 새로 게시한 정상 콘텐츠는 앱 재설치 없이 받을 수 있어요.

## 학습 현황 대시보드

[학습 현황 열기](https://jhs512.github.io/immersion-quest-3/dashboard/)에서 코스 저장소를 선택하세요. 학생별 완료율, 마지막 통과 문제와 수업별 진도를 확인할 수 있어요.

GitHub에 전송된 공개 기록을 조회해요. 관리자 전용 비공개 화면은 아니에요. 코스별 표시 이름과 GitHub 계정을 함께 보여줘요. 조회 버튼을 누르면 최신 기록을 다시 불러와요.

## 코스별 이름과 진도 저장

코스에 처음 들어가면 **이 코스에서 쓸 이름**을 입력하세요. 이름의 공백은 자동으로 없애요. 같은 계정도 코스마다 다른 이름을 쓸 수 있어요. 코스 목록에서 이름을 바꾸면 기존 진도는 유지하고, 대시보드에서 다시 조회할 때 새 이름이 보여요.

이름은 코스 등록 이슈에 바로 전송해요. 진도는 먼저 기기에 저장하고, 같은 수업의 이슈에 5분 간격으로 모아 전송해요. 창을 닫거나 Ctrl+Q로 종료하면 별도 프로세스가 남은 기록을 전송해요. Mac의 ⌘Q도 지원해요. 연결 실패 시 기록을 보관했다가 다음 실행에서 다시 시도해요.

같은 기기의 같은 GitHub 계정에서 종료 전송을 24시간 안에 10번 시도하면, 10번째 시점부터 24시간 동안 추가 종료 전송을 멈춰요. 평소 5분 간격 전송과 기기 안의 진도 저장은 계속돼요. 보낼 기록이 없는 종료는 횟수에 넣지 않아요.

## 특정 코스의 수업 링크

수업 목록이나 학습 화면에서 **수업 링크 복사**를 누르세요. 웹 링크의 **MQ에서 수업 열기**를 누르면 설치된 앱에서 해당 코스의 수업을 열어요. 최신 앱과 GitHub 로그인이 필요해요. 처음 참여하는 코스라면 이름부터 입력해요.
