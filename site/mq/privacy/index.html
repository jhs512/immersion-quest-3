몰입 퀘스트 3
내려받기

개인정보처리방침

몰입 퀘스트 3(앱 이름 MQ)이 어떤 정보를 어디에 두고, 어디로 보내는지 적었어요.

기준: 2026년 11월 21일 공개 앱(v0.1.0-build.191)의 동작이에요.

1. 기기에 저장하는 것

앱은 아래 폴더에 학습 자료를 저장해요.

  • Windows: %LOCALAPPDATA%\MolipQuest\MolipQuest\data
  • macOS: ~/Library/Application Support/MolipQuest.MolipQuest

이 폴더에 들어가는 것은 다음과 같아요.

  • 작성 중인 답안
  • 학습 기록과 아직 보내지 않은 진도
  • 코스별로 쓰는 이름과 전송 대기 상태
  • 앱 설정, 해설 음성 선택과 말 속도
  • 받은 코스·수업 콘텐츠와 업데이트 파일
  • 실습에 쓰는 도구와 실습 폴더
  • 해설 음성 파일(한 번 받은 문장의 음성)
  • 진단 기록과 신고 초안(아래에서 설명해요)

진단 기록

앱은 동작이 느리거나 실패한 지점을 찾으려고 진단 기록을 남겨요. 이 기록은 기기 안에만 있어요. 앱이 저절로 밖으로 보내지 않아요. 여러분이 신고를 보낼 때만 함께 가요.

진단 기록에는 정해 둔 항목만 들어가요.

  • 작업 이름, 걸린 시간, 성공·실패
  • 코스·수업·문제의 식별자와 언어
  • 결과 상태, 오류 종류와 번호, 검사 수와 실패 수
  • 실습 도구 종류, 패키지 이름, 프로그램 종료 코드
  • 앱 화면 오류가 난 파일 이름과 줄 위치
  • 앱 빌드·버전, 운영체제 종류, CPU 종류

작성한 소스 코드, 터미널 명령과 출력, 주소(URL), 토큰, 오류 메시지 본문은 넣지 않아요.

상세 실행 기록은 최근 한 시간만 남겨요. 화면 이동 이력은 최대 180일까지 남겨요. 둘 다 건수 상한이 있어서 넘치면 오래된 것부터 지워요.

GitHub 로그인

GitHub 로그인은 GitHub CLI(gh)로 해요. 앱은 GitHub에 요청할 때 gh를 거쳐요. 로그인 정보는 앱이 아니라 gh가 관리해요.

2. GitHub로 보내는 것

학습 기록은 여러분의 GitHub 계정으로, 코스 저장소에 이슈를 만들어 남겨요. 다른 서버로 보내지 않아요.

코스 등록

코스에 처음 들어가면 그 코스에서 쓸 이름을 입력해요. 앱은 코스 저장소에 「[등록] 이름 · @GitHub 계정」 이슈를 만들어요. 본문에는 이름, GitHub 계정 번호, 코스 식별자, 수정 시각이 들어가요. 이름을 바꾸면 같은 이슈를 고쳐요.

진도

수업마다 「[진도] 수업 제목 · @GitHub 계정」 이슈를 하나 만들어요. 그다음 기록은 그 이슈의 댓글로 더해요.

기록 하나에는 이런 항목이 들어가요.

  • 무슨 일이었는지: 시작, 시도, 통과, 해설 보기, 예제 실행, 초기화 등
  • 시각, 코스·수업·문제 식별자, 수업 버전, 통과 여부
  • 실행 전에 예상을 고르는 문제라면 고른 예상

진도는 먼저 기기에 저장해요. 그다음 5분 간격으로 모아 보내요. 연결에 실패하면 보관했다가 다음 실행에서 다시 보내요.

누가 볼 수 있나요?

공개 코스 저장소의 이슈는 누구나 볼 수 있어요. 코스에서 쓰는 이름, GitHub 계정, 진도도 함께 보여요. 학습 현황 대시보드도 이 공개 기록을 모아 보여 줘요.

업데이트 확인

앱은 GitHub에서 새 앱 버전과 새 수업 콘텐츠를 확인하고 받아요.

3. 신고할 때 보내는 것

신고는 여러분이 신고 창에서 설명을 쓰고 보내기를 눌렀을 때만 가요. 화면 캡처를 넣을지도 그 창에서 골라요.

  • 앱 오류 신고(신고 버튼, Ctrl+Alt+Shift+B): jhs512/immersion-quest-3 저장소의 이슈로 올라가요.
  • 문제 신고(Ctrl+Alt+Shift+P): 지금 연 수업의 저장소에 이슈로 올라가요.

이슈 본문

  • 여러분이 쓴 설명
  • GitHub 계정
  • 코스·수업·단계의 이름과 식별자, 수업 버전
  • 앱 빌드, 운영체제와 CPU 종류
  • 오류가 나거나 2초 넘게 걸린 작업 요약
  • 진단 파일 링크

진단 파일

진단 파일은 여러분 계정의 비공개 gist(Secret gist)로 올라가요. 비공개 gist는 목록에 나오지 않을 뿐이에요. 링크를 아는 사람은 누구나 열 수 있어요.

gist에는 위의 진단 기록이 들어가요. 화면 캡처를 넣기로 했다면 MQ 창의 캡처도 들어가요.

gist 링크는 이슈 본문에 들어가요. 그래서 이슈를 볼 수 있는 사람은 진단 파일도 열 수 있어요. jhs512/immersion-quest-3는 공개 저장소라서 앱 오류 신고는 누구나 볼 수 있어요. 문제 신고는 그 수업 저장소의 공개 설정을 따라요.

신고 초안과 캡처는 기기에도 남아요. 새 신고를 만들 때 최근 신고 9개만 남기고 나머지는 지워요.

4. 해설 음성

해설 음성은 설정에서 골라요.

  • 선히·인준·현수(인터넷 필요): 읽을 문장을 Microsoft Edge 「소리 내어 읽기」 음성 서비스로 보내고 음성을 받아요. 앱은 이를 위해 edge-tts 도구를 써요. 보내는 것은 해설 문장이나 여러분이 읽기를 시작한 화면 글이에요.
  • 받은 음성은 기기에 저장해요. 같은 음성으로 같은 문장을 다시 읽을 때는 저장한 음성을 써요.
  • 기기 기본 음성: 앱이 문장을 Edge 음성 서비스로 보내지 않아요. 운영체제의 음성 기능으로 읽어요.

5. 문의

이 방침에 대한 질문은 GitHub Issues에 남겨 주세요. 이슈는 공개돼요. 개인 정보는 적지 마세요.
