Mac · 터미널로 설치

Apple Silicon Mac에서 사용하세요.
Spotlight(⌘ + Space)에서 터미널을 여세요.
아래 명령을 붙여 넣고 Enter를 누르세요.

curl -fsSL https://raw.githubusercontent.com/jhs512/immersion-quest-3/main/packaging/macos/install.sh | bash

설치 파일을 브라우저로 받아 실행하지 마세요.
터미널 명령으로 설치와 환경 준비를 함께 진행해요.

브라우저에서 앱을 열지 물으면 허용하세요.
GitHub 로그인 후 연결된 코스나 수업으로 이동해요.
