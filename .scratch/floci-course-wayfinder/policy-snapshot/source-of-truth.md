# 과정과 수업의 제작 기준

2026-11-09 사용자 지시를 적용한다.

과정의 진실의 원천은 `tools/redesigned_courses/catalog.json`의 코스 교육 목표(`objectives`)와 전체 흐름(`core_flow`)이다. 전체 흐름은 수업의 추천 순서뿐 아니라 각 묶음을 그 위치에서 배우는 이유를 기록한다. 앱의 자유로운 수업 선택과 구별한다.

각 수업의 진실의 원천은 `tools/redesigned_lessons/<folder>/lesson-preview.json`의 수업 예고다. 예고에는 배울 관계, 차례로 겪을 경험, 마지막에 직접 수행할 일, 전제와 제외 범위, 탐구할 질문을 담는다. 홍보 문구나 이미 만든 문제의 요약으로만 관리하지 않는다.

제작 순서는 코스 목표·전체 흐름 → 수업 예고 → PRD의 챕터·단원·스텝별 목표와 상세 핵심 흐름 → 실제 문제·정답·채점 → 해설과 보충 자료다. 예고는 학습자에게 약속한 수업이고 PRD는 그 약속의 상세 구현 명세다. `GLOSSARY.md`의 교육 목표·핵심 흐름·학습 콘텐츠·부가 설명 자료 관계는 각 단계 안에서 유지한다.

## 파일과 검사

- `lesson-preview.json`이 학생에게 보이는 수업 예고 원본이다. 코스 빌더가 세 과정 모두에 동일하게 전달한다. 별도 Python 사전을 수정해 화면에만 다른 약속을 만들지 않는다.
- 예고의 `course_intent_sha256`은 코스 목표와 전체 흐름에 묶인다. 둘 중 하나가 바뀌면 해당 과정의 예고 영향을 검토한다.
- `preview-alignment.json`은 예고와 PRD 목표·핵심 흐름, 문제·준비 코드·정답·채점·변형의 관계를 검토한 기록이다. 하나가 바뀌면 빌드가 멈춘다. `tools/review-curriculum-alignment.py`에 수업·검토 이유·상태를 명시해서 갱신한다. 빌드에서 자동으로 새 해시를 찍지 않는다.
- 코스 전체 흐름은 모든 등록 수업을 추천 순서대로 한 번씩 포함해야 한다.
- 해시는 변경 누락을 잡는 장치다. 교육적 의미가 맞다는 증명은 아니다. 검토자는 바뀐 약속을 실제 스텝의 행동·관찰 결과·채점과 대조한다.

## 기존 자료 이관의 한계

자바의 기존 예고 원문은 그대로 옮겼다. 예고가 없던 두 과정은 기존 목표·단원 순서·최종 문제에서 내용을 손실 없이 이관했다. 이 이관은 과거부터 예고 우선 제작이 이루어졌다는 증거가 아니다.

기존 112개 수업에는 `migration_needs_semantic_review`를 남긴다. 구조 점검 완료와 의미 정독 완료를 구별한다. 새 네트워크 수업은 예고를 먼저 정하고 PRD·문제·실행 결과를 대조한 `reviewed` 기록을 쓴다. 이전 승인·진도·답안·문제 ID를 이 이관 때문에 바꾸지 않는다.

점검 결과는 `source-of-truth-before-2026-11-09.md`와 `source-of-truth-audit-2026-11-09.md`에 있다. 전체 수업의 남은 객관식·결과값 입력과 선수 경험 원장 누락을 포함한다.
