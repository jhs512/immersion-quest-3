# 첫 적용은 네트워크 보강인가 후속 AWS 실습인가

Status: resolved

Parent: [Floci를 활용한 MQ 클라우드 실습의 적용 경로](../map.md)

## Question

기존 네트워크 수업의 필수 실습은 유지하고, Floci는 S3·SQS 같은 AWS 기능을 직접 다루는 후속 수업 후보로 조사할 것인가? 또는 기존 네트워크 보강이나 새 AWS 기초 코스 전체를 우선할 것인가?

## Comments

후속 AWS 실습을 추천하는 질문을 사용자에게 제시했다. 답변 전에는 결정을 닫거나 사용자 대신 승인하지 않는다.

## Answer

2026-11-09 사용자와의 음성 대화에서 기존 네트워크 실습을 유지하고 후속 클라우드 인프라 실습을 검토하기로 했다. 사용자는 쉬운 것부터 진행하기를 원했으며, VPC·서브넷 구축을 먼저 다룰 수 있는지 질문했다. 따라서 S3 선행을 확정된 수업 순서로 고정하지 않는다. 사용자 요청에 따라 실제 로컬 실험을 먼저 수행해 구성 API와 실제 통신의 차이를 확인한다.

### 실험 후 사용자와 정한 순서

맥에서도 같은 동작을 한다고 가정해 수업 범위를 논의하되, 이를 Mac 실행 검증으로 간주하지 않는다. 사용자는 클라우드 인프라 목표라면 VPC·서브넷·EC2 구성과 수명주기를 먼저 다루고 그다음 S3로 넘어가는 방향에 동의했다. 따라서 첫 묶음은 주소 공간·서브넷·서버 배치·운영·의존성에 맞춘 정리이며, S3는 후속이다. S3 다음은 아직 확정되지 않았고 SQS를 후보로 제안한다. 기존 라우팅·NACL·NAT 실제 패킷 실습을 Floci로 대체하는 결정은 아니다.
