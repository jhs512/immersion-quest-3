| 구분 | 현재 근거 |
|---|---|

| 정리 | 최종 두 부분 모두 컨테이너·네트워크 전체 inspect·볼륨·context 전후 동일 |

| MQ 네이티브 연결 | 2026-11-10 Windows 단위 10개·실제 Docker 경로 8개 통과. 첫 실패·재실행 기록 보존. 실제 제출 분기·상태 보존·정리를 검사함 |
| 본편·해설·등록 | 2026-11-10 7개 실습 제작·자바 과정 등록. 공개 수업 JSON을 네이티브 제출 경로로 실제 실행해 7개 모두 확인(초기·오답 실패, 해설 통과, 초기화, 해설 분리, 변형) |
| 배포·앱 화면 | 미완료·미검증(게시·설치 앱 반영 없음, 앱 화면·음성 미확인) |
