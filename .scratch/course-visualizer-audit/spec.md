# 모든 코스 레벨링 및 비주얼라이저 해설 감사

## 사용자 요청, 2026-11-02

- Windows/macOS에서 Java, C, Python, JavaScript, C++, Rust 코드 실행 비주얼라이저를 지원한다.
- 코드 실행 문제는 기본 표시하고 명시적으로 끈 단계만 숨긴다.
- 자바 백엔드 과정 초반에 Rust 기초 수업 약 네 개를 추가한다.
- 모든 코스의 수업을 재검토하고 계획을 세운 다음 수행한다.
- 해설에서 비주얼라이저가 이해에 도움이 되면 사용한다. 불가능한 환경에는 강요하지 않는다.
- 빅데이터 예제에 적용 가능한지는 데이터 크기와 비용을 실제로 실험한다.
- 공통 레벨링 상위 원칙을 근거에서 추출해 루트 AGENTS.md에 둔다.
- 전반적인 코스 감사와 개선은 Claude가 맡는다.

## 완료 조건

1. 실제 코스 manifest와 수업 참조를 전수 대조한 코스별/고유 수업별/스텝별 행렬이 있다.
2. 상위 원칙은 실제 정책과 사용자 결정의 근거를 가지며 AGENTS.md에 기록돼 있다.
3. 각 수업의 목표·선수 관계·도입/연습/조합·정답/초기 코드·해설/평가 정합성을 판단하고 근거를 기록한다.
4. 비주얼라이저 적용/비적용/불가/보류에 이유와 실험 근거가 있다.
5. 데이터 규모별 실제 실행 시간, 추적 크기, 메모리 비용과 UI 반응을 관찰한다. 일반화할 수 없는 환경 한계를 구분한다.
6. 안전한 국소 개선은 적용하고 실제 검증한다. 구조 재설계는 계획을 먼저 남긴다.
7. 새 Rust 수업은 PRD와 대표 문제를 승인받은 뒤 정식 제작한다.

## 경계

이 checkout은 Claude 전용이다. 다른 checkout과 사용 중인 앱/학습자 파일·진도는 수정하지 않는다.
네이티브 실행기, 플랫폼 설치, 언어 enum, src/player_ui.rs 및 release workflow는 Codex 통합 작업이다. 코스/해설/정책/제작 검증 도구를 맡는다.
JS·C++·Rust 실행기 지원은 아직 구현 중이다. 버튼의 기본 노출과 실제 실행 가능성을 구분한다.
Mac C는 실제 ARM/Intel 기초 실험과 Rust 호출 통합을 통과했고 전체 79개 C 문제 검사가 진행 중이다.
